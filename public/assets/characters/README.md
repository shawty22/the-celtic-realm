# Character Art Assets

Drop final character art here as PNG files. The app loads them automatically and
falls back to the procedural glyph drawings if a file is missing.

## Expected filenames (name-glyph.png)

| File                  | Character         | Realm          |
|-----------------------|-------------------|----------------|
| branna-selkie.png     | Branna — Selkie   | Moon Pond      |
| corrig-kelpie.png     | Corrig — Kelpie   | Moon Pond      |
| aoife-faerie.png      | Aoife — Mist Faerie | Brigid's Grove |
| nairi-wisp.png        | Náiri — Will-o'-Wisp | Fairy Mound  |
| puck-puca.png         | Puck — Púca       | Mist Gate      |
| lughan-raven.png      | Lughan — Raven Spirit | Tír na nÓg |

## Art direction

Characters should be painted on a **transparent background** (PNG with alpha).
Portrait orientation, roughly 600×900px or taller. Bright, slightly luminous —
as if lit from within. Each character comes with a soft glow painted around them
in their glyph colour.

See `/src/data/creatures.json` for each character's palette and lore reference.
